# GPT4o_vs_GPT6Astra_Markov_Models
This repository includes R scripts generated using GPT-4o and GPT-6 Astra via the ChatGPT web interface. The scripts comprise 60 experimental runs aimed at replicating two versions of a published Markov cost-effectiveness model of temozolomide for glioblastoma. This study compares the replication accuracy of both LLMs against the published model.
